# Samarth Kukreja — Portfolio

A responsive, static personal portfolio for GitHub Pages.

## Deploy with GitHub Pages

1. Create a public repository named **`SamarthKukreja.github.io`**.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Your site will be available at `https://SamarthKukreja.github.io/` after GitHub Pages finishes deploying.

## Local preview

Open `index.html` in a browser. No build tools or dependencies are required.

## Before publishing

- Confirm the project metrics (93%, 91%, 84%) match the evaluation metrics used in the project reports.
- Add the public ERP source-code URL if one is available.
- Confirm the OCIT 2026 proceedings wording and update the publication status after presentation/publication.
- Add a professional headshot if desired; the current design intentionally uses a typographic identity mark.
